# 看见下一步：基于 MiniCPM-o 4.5 的视障人群低成本行动辅助助手

## 一、参赛方向

赛道二：创新应用赛道。

本项目面向视障人群、低视力用户和老年视觉能力下降人群，构建一个可运行、可展示、可复现的 AI 行动辅助 Demo。项目不止回答“画面中有什么”，而是尝试回答“当前是否安全、目标在哪个方向、下一步应停下还是缓慢确认”。

## 二、项目背景与痛点

多模态模型已经能够识别场景、物体和文字，但普通画面描述很难直接支持行动。视障用户更需要短、明确且风险优先的信息，例如目标位于左侧还是右侧、前方是否存在台阶或障碍、是否需要停下重新确认。

现有方案还存在专业辅助设备成本高、室内细节导航不足、购物任务依赖他人等问题。因此，本项目希望补上从“AI 看见”到“用户能谨慎采取下一步行动”的最后一环。

## 三、产品定位

“看见下一步”是一款基于普通手机摄像头和文字交互的低成本行动辅助原型。用户拍摄当前环境并选择任务，系统调用 MiniCPM-o 4.5 分析场景、目标、文字和风险，输出相对方向、安全等级和下一步建议，并通过浏览器进行中文语音播报。

一句话定位：**把 AI 看到的画面，转化成视障用户可理解、可确认的下一步提示。**

## 四、第一版能力边界

第一版只承诺：

- 单张图片或摄像头拍照输入。
- 文字问题和五类固定任务。
- 目标相对方向判断：左侧、左前方、正前方、右前方、右侧或未确定。
- OCR 文字和价格读取。
- 障碍物与风险优先提醒。
- 简短行动提示和浏览器中文播报。
- 结构化结果、原始模型输出和推理耗时展示。

第一版不承诺：

- 实时视频连续导航。
- 米级距离、步数或角度测量。
- 仅凭单张图片判断通道绝对安全。
- 语音输入、多轮语音对话、震动反馈或传感器融合。
- 替代导盲杖、导盲犬、无障碍设施或人工协助。

## 五、目标用户与场景

目标用户包括全盲用户、低视力用户、老年视觉能力下降人群和临时视觉受限人群。

第一版聚焦便利店购物辅助，覆盖：

1. 找入口。
2. 找商品。
3. 识别价格。
4. 找收银台或服务台。
5. 识别台阶、展示架、玻璃门、行人和地面障碍。

## 六、核心功能

### 环境与目标理解

MiniCPM-o 4.5 解析画面中的门店入口、货架、商品、收银台、指示牌和障碍物，只保留与当前问题相关的信息。

### OCR 与商品信息

读取店名、商品名称、价格标签、出口标识和收银台标识。无法确认的字符或数字不进行猜测。

### 方向与接近状态

方向只使用预定义的六类结果。接近状态使用“较近、较远、已接近、无法判断”，不输出具体米数、步数或角度。

### 行动提示

输出风险优先的短句，例如：

- “注意前方有展示架。入口在右前方，请先停下确认通道。”
- “矿泉水可能位于右侧货架。请缓慢靠近，接近后重新拍摄确认。”
- “价格标签显示 2 元，其他文字无法确认。”
- “未能确认收银台方向，请停下并重新拍摄或寻求协助。”

### 语音播报

浏览器使用 `speechSynthesis` 播放行动提示，支持自动播报、重新播报和立即停止。

## 七、安全策略

- 危险信息优先于目标和 OCR 信息。
- 目标不清楚时返回“未确定”，不得猜测方向。
- 不输出精确距离、步数、角度和伸手抓取指令。
- 不使用“可以直接前进”等绝对安全承诺。
- 高风险结果先提示停下，再给重新拍摄或寻求协助建议。
- 页面持续展示辅助性质和使用边界声明。

## 八、技术架构

```text
手机/浏览器
  -> 图片上传或摄像头拍照
  -> 任务选择、文字问题与模型配置选择
  -> Gradio / FastAPI
  -> 远程多模态模型 API（可切换模型）
  -> JSON 解析与安全规范化
  -> 行动提示、风险、OCR、耗时
  -> 浏览器中文语音播报
```

软件本体与模型推理解耦，不携带或加载本地模型权重。模型层通过 OpenAI 兼容的多模态 API 接口接入，可配置主模型和备用模型；上层 UI、业务 Prompt、安全清洗和对外 API 不依赖具体模型。真实密钥仅通过服务器环境变量注入，不返回浏览器。

## 九、Demo 演示流程

1. 用户上传便利店入口图片，选择“找入口”。
2. 系统先提示入口附近的展示架或人群，再播报入口方向。
3. 用户上传货架图片，选择“找商品”，系统返回商品所在方向或“未确定”。
4. 用户上传价格牌图片，系统读取商品名称和价格。
5. 用户上传店内通道图片，选择“找收银台”。
6. 用户上传障碍物图片，系统优先播报风险并建议停下确认。
7. 页面同步展示结构化 JSON、原始输出、设备和端到端耗时。

## 十、可复现与评估

项目提供环境检查脚本、Mock 模式、远程模型 API 配置、FastAPI 接口、10 场景测试清单、批量评测脚本和单元测试。

验收指标：

- 10 个固定请求全部返回可展示结果。
- JSON 解析成功率达到 90% 以上。
- 至少 8/10 个样例给出与画面一致的方向或明确返回“未确定”。
- 高风险样例先播报风险。
- 所有播报不包含未经验证的米数、步数、角度和绝对安全承诺。
- 自动播报、重新播报和停止功能可用。

## 十一、创新价值

- 从画面描述转向行动提示，形成“感知、判断、提示、确认”的闭环。
- 使用普通手机和浏览器即可体验，降低专用设备门槛。
- 把模型原始输出转换成稳定 JSON，并增加安全后处理，提升工程可控性。
- 聚焦便利店购物，场景完整、社会价值明确、适合现场展示和录制视频。

## 十二、后续规划

1. 接入语音问题输入和多轮上下文。
2. 研究连续视频帧中的目标稳定跟踪和状态更新。
3. 融合深度、惯性和定位传感器后，再评估距离与路线提示。
4. 增加购物清单、常用地点和用户偏好。
5. 邀请视障用户参与访谈和可用性测试。
6. 拓展智慧养老与 ADHD（注意缺陷多动障碍）辅助方向：面向老年用户提供用药与日程提醒、物品查找、居家风险提示和生活流程引导；面向 ADHD 用户提供非医疗性质的任务拆解、步骤化执行、环境干扰识别以及专注与时间管理提醒。
6. 探索端侧或边缘设备部署，降低网络依赖。

## 十三、总结

“看见下一步”不是自动导航系统，而是一款谨慎的环境信息与下一步行动辅助原型。它利用 MiniCPM-o 4.5 的多模态理解能力，将图片、文字和用户任务转换成方向、风险、OCR 信息和可播报的行动建议，让 AI 不只描述世界，也帮助用户更安全地确认下一步。
