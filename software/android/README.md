# 手机本地程序

WiFi 摄像头上电后把 JPEG 送到这台手机。手机调用现有云端 `/infer`，再把短句交给眼镜播报。模型不在手机上。

微信小程序仍用手机自己的摄像头。云端 `/glasses/` 仍是本机摄像头演示。

## 眼镜和摄像头怎么连

1. 打开手机热点。Android 热点的网关一般是 `192.168.43.1`。
2. 安装并打开这个应用，填上网关地址和口令，点「开始接收」。
3. 摄像头连上热点，大约每 2.5 秒 `POST http://192.168.43.1:8788/frame`，正文是 JPEG。
4. 眼镜的浏览器打开 `http://192.168.43.1:8788/`。这一页只有按住说话和朗读，没有镜头。

手机还在等网关时，`/frame` 返回 429。摄像头丢掉这一帧，不要排队。没有新的话、并且上次识别没有要求继续看时，手机只留下这一帧，不上传。`client` 固定为 `phone`：图来自 WiFi 摄像头，这句话来自眼镜。

## 用电脑看播报页

Android Studio 打开本目录即可编译。帧该不该上传的规则在 `hub_policy.py`，测试随网关那组单元测试一起跑。
