# 看见下一步 · 客户交流话术 v1

给谁用：见视障用户、家属、残联/机构、渠道、评委。  
原则：**先说他能听见什么、手能做什么；边界放在后半句，不要一开口先念免责声明。**  
不讲：二维空间、网关、distance_band、FMCW、异构复核、SLAM、APP_TOKEN。

---

## 1. 三十秒（任何人）

戴着眼镜或举着手机，朝哪看，我就说哪边、远不远、要不要先停。  
你说「帮我找可乐」，后面一直找可乐，不会说完就忘。  
手杖还是要拿着。我是旁边帮看的人，不是替你走路的人。

手机扫码就能用。眼镜是为了腾出手、对得准你正在看的方向。

---

## 2. 两分钟（愿意听完的人）

超市里把货架拍给聊天软件，它会说「有货架、有灯」。人要的是：第几排、左边还是右边、手往哪伸、要不要先停。

我们只做这一小步。画面变成一句能执行的话，比如：

> 正在帮你找可乐，左前方货架中部，比较近。先停一下。

远近不报米数。报「一臂内、较近、较远」——听完身体有数，又不会被错误数字带着往前走。

现在用微信就能试。下一步把同一双「眼睛」放到眼镜上：摄像头认方位、认是什么；雷达或测距看正前方有多近。两件事分开，合在一句里说给你听。

---

## 3. 换对象，换说法

### 视障用户（对面坐着、要试用）

先问他常卡住的一件事：找饮料、找门、找收银台。不要先介绍架构。

可以说：

- 你朝哪转，我就看哪。
- 你按住说话，说要找什么。松开之后，我边看边说。
- 近了我会震一下。不确定我就说还在找，不会瞎编已经看到。
- 手杖照常用。过马路别听我的。

不要说：实时推理、丢帧、主任务记忆。可以说：我说太快你让我停；同一句我尽量不反复念。

### 家属 / 护理

先安「会不会比手机危险」：

- 比举着手机安全一些：手空出来，镜头跟着脸。
- 不会让他「可以往前走」。看不清就停。
- 充电是磁吸，吸住就开始充，不用对小孔。线连着口袋里的盒子，眼镜滑下来会挂在衣服上，镜头不容易砸地上。门上刮到线会自己断开，不会勒脖子。
- 电不多了会说话、会震，不用盯屏幕。

价格若问到：专用眼镜国外要一两万到三万；我们先做能戴的样子，识别跑在已经在用的服务上，不重复造一个封闭大脑。

### 机构 / 残联 / 渠道

三句话：

1. 零硬件可试用（微信），降低培训成本。  
2. 眼镜是同一套说法，不是另一个 App。  
3. 辅助，不替代杖、犬、设施；合同和培训材料里写明。

演示只跑货架、门口、收银台。不要演示马路牙子当过马路。

### 技术客户 / 评委（他们自己会问模型）

可以讲模型名，但仍用人话收口：

- 看图的模型负责「是什么、在哪一侧」。现在是一档，以后可以换成更好的多模态；对人说的还是那句下一步。
- 测距不靠它编数字，靠雷达或测距元件，再翻译成远近。
- 不清楚的词（米、步、角度）网关会洗掉，不播给用户。
- 长期记忆（记忆张量）记得这个人常买什么；不把记忆模型当成眼睛。

## 4. 眼镜 + 雷达，客户问「是不是就能定位测距」

**短答：**  
能做基本的。摄像头告诉你在哪一侧、那是什么；雷达告诉你正前方远不远。合起来就是「左前方，比较近」。不是尺子，也不是导航地图。

**加一句就够的类比：**  
像旁边的人用手一指：「这边，伸手就到。」他不会掏出卷尺。

| 客户原话 | 别这样接 | 这样接 |
|---|---|---|
| 能测距吗？ | 我们有毫米波，精度可达毫米。 | 能告诉你近不近。近到一臂之内我会请你先停。不报「37 厘米」。 |
| 能知道方位吗？ | 我们做二维空间六向枚举。 | 左、左前、正前、右前、右。听完手知道往哪侧偏。 |
| 有雷达是不是就能出门？ | 可以避障导航。 | 正前方有东西靠近，我会提醒。地面、马路还是要靠手杖。 |
| 和豆包有什么区别？ | 我们是多模态行动辅助系统。 | 豆包描写画面。我们说下一步。 |
| 你们用哪个模型？ | 我们用小米 MiMo。 | 现在用一档看图模型。以后换成更好的，你听到的还是那句下一步。 |
| 会不会越用越懂我？ | 我们接入了记忆操作系统。 | 你常买什么、怎么叫家里那只杯子，说过一次可以记住。你说忘掉就忘掉。 |
| 和 Envision / 小米眼镜呢？ | 他们没有我们的融合算法。 | Envision 很完整但很贵。小米眼镜轻，但不说货架下一步，也没有测距带。我们先把「听得懂的下一步」做好，眼镜只是换个戴法。 |
| 准吗？ | 准确率 95%。 | 看不清就说还在找。宁可少说，不带错路。 |
| 能过马路吗？ | 高风险会提示。 | 不能。过马路不要用这个。 |
| 多重？能戴多久？ | 我们做了轻量化设计。 | 脸上目标五十克上下。充电盒放口袋，线一吸就能边用边充；掉了也挂着，不摔地上。 |

## 5. 现场演示（超市或会议室货架）

开场不要调设置。戴上或打开小程序，对着人说：

1. 「我先让它自己看。」（实时，等一句口语）  
2. 「现在我说：帮我找矿泉水。」（按住说话）  
3. 「你听：它还在找同一瓶，没有改口说通道。」  
4. 若有测距：「我靠近一点。它应该说更近，或者震一下。」  
5. 收尾：「手杖我没放下。它只是多了一双眼睛。」

失败了怎么圆：  
「它这句没看清。我们设计成不编。我换个角度再让它看。」  
不要解释 429、丢帧、token。

## 6. 产品里客户听得到的句子（对照）

开机、按钮、安全提示也是交流。法务句放后面，前面先说要干什么。

| 场景 | 以前像说明书 | 对人说 |
|---|---|---|
| 眼镜欢迎 | 本软件只提供环境信息辅助，不能替代… | 朝前看，我说哪边、近不近。手杖照拿，过马路别靠我。 |
| 开始键 | 戴上，开始辅助 | 开始看 |
| 按住说话 | 按住说话说出需求 | 按住，说要找什么 |
| 精确确认 | 精确确认 | 再看一眼 |
| 口令 | 业务口令 / 填写口令 | 使用密码 |
| 距离 | 距离带、VisionKit、LiDAR | 远近：一臂内、较近、较远 |
| 没看见 | 未能确认目标，请重新拍摄 | 还在帮你找。眼前是货架。 |
| 记下任务 | 已记下主任务：找可乐 | （不要播）直接开始找 |
| 电量 | 电量 18% | 电不多了，该吸上充电了 |

播报范例（对外演示就用这三句，不要更长）：

- 正在帮你找可乐，左前方货架中部，比较近。
- 注意，前面有玻璃门。还在帮你找入口，门在右前方。
- 还在帮你找收银台，正前方是通道，先停一下。

---

## 7. 禁止出口的词（对客户）

精度厘米、点云、实时导航、自动驾驶、世界模型、替代导盲、绝对安全、保证通道、SLAM、异构、JSON、推理延迟、丢帧。

被问到技术细节：用一句人话回答，再问「要不要看手机上怎么用」。多数客户要的是信任，不是参数表。

---

## 8. 收尾一句（名片级）

**看见下一步：朝哪看，说哪边；近了请你停。手杖仍在你手里。**
