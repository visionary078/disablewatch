# 眼镜上机检查

软件测试在 GitHub 上自动跑。硬件没有自动台架，每台样机用这一份人工检查。原则和策划案一致：脸上尽量轻，摄像头在眼前，不替代导盲杖，不承诺过马路，不对用户报米数。

复制 [record.md](record.md)，填日期、样机编号和每一项的结果，放到 Pull Request 里。做不到的项写「未做」和原因，不要留空。

## 每次样机都要看

| 项 | 怎么判通过 |
|---|---|
| 能戴上、能摘下 | 戴正后不夹太阳穴；摘下时镜腿不把镜框拽变形 |
| 脸部重量 | 取下颈后电池后称镜框。目标 ≤ 55 g，超过 80 g 这版不能当可戴样机 |
| 摄像头位置 | 在鼻梁附近、接近眼睛高度。不把胸口摄像头当主摄像头 |
| 看向前方 | 头正对货架或门时，画面中心是人正在看的方向，不是地面或天花板 |
| 充电 | 能充进电，充满后能开机。充电口或磁吸触点朝下或在脑后，盲操摸得到 |
| 线被拉一下 | 磁吸或易断连接会松开，镜框不被拽着走。记下大约用多大力拉开 |
| 摘下后安静 | 摘下或不在脸上时，不继续对着空场景播报 |
| 说话方式 | 只说在哪一侧、近不近。不出现「前方 1.2 米」这类米数 |

## 有传感器时再加

| 项 | 怎么判通过 |
|---|---|
| 一臂内 | 伸手能够到的东西，被说成近 |
| 较近 / 较远 | 再远两档能分开，不要求厘米 |
| 只震不说 | 近处障碍可以只震动，不每次都说话 |

## 明确不测成卖点

- 不测「能不能自己过马路」
- 不把导盲杖或导盲犬从流程里拿掉
- 不用太阳能、走路发电当作续航承诺
